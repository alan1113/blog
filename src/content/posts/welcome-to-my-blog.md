歡迎來到我的個人部落格！

這座小島是利用 [Astro](https://astro.build/) 與 [AstroPaper](https://github.com/satnaing/astro-paper) 主題打造的，並透過 GitHub Actions 與 GitHub Pages 完成了現代化的自動部署流程。

## 網站特色

1. **極速靜態渲染**：Astro 預設零 JavaScript 的架構，讓頁面載入飛快。
2. **自動化 CI/CD**：透過 GitHub Actions，每次發布 Pull Request 或推送到 main 都會自動進行代碼格式檢查與網站部署。
3. **優雅的排版與深色模式**：支援程式碼語法高亮、繁體中文排版，並能在深淺色主題間切換。
