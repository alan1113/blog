歡迎來到 **Alan's Blog**！

這裡是我記錄學習歷程、軟體開發技術與心得分享的個人空間。

## 關於本站

本站基於 [Astro](https://astro.build/) 與 [AstroPaper](https://github.com/satnaing/astro-paper) 主題建置，並透過 GitHub Actions 自動化部署至 GitHub Pages。

- **極速載入**：純靜態網站，極致輕量與流暢
- **支援深色模式**：隨心切換明暗主題
- **工程化流程**：使用 Git、GitHub Actions CI/CD 與 Pull Request 進行內容發布與品質控管
